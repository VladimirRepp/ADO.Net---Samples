# ADO.NET Authors CRUD (WinForms, MVC-подобная структура)

Простое учебное приложение на **C# WinForms**, демонстрирующее подключение к базе данных и выполнение **CRUD-операций** через **ADO.NET**.

Проект является логическим продолжением предыдущей версии, где весь код находился в одном файле. Теперь код разделён по слоям (по принципу **MVC**) — это делает его чище, читаемее и удобнее для расширения.

---

## 📋 Возможности

- Подключение к базе данных через `SqlConnection`
- Просмотр списка авторов
- Добавление нового автора
- Редактирование существующего автора
- Удаление автора
- Разделение ответственности между слоями (Model / Controller / View / Connection)

---

## 🗂 Структура проекта

```
├── Models/
│   └── Author.cs                 # Модель "Автор"
├── Controllers/
│   └── DbAuthorsController.cs    # Контроллер для работы с авторами в БД
├── Database/
│   └── DbConnection.cs           # Класс подключения/отключения к БД
├── Views/
│   └── Form1.cs                  # Представление (UI)
└── Program.cs                    # Точка входа
```

### Описание классов

| Класс | Назначение |
|-------|-----------|
| **`Author`** | Модель, описывающая одного автора (Id, Name и т.п.) |
| **`DbAuthorsController`** | Контроллер со всеми действиями с БД (SELECT / INSERT / UPDATE / DELETE) для авторов |
| **`DbConnection`** | Инкапсулирует открытие и закрытие подключения к БД |
| **`Form1`** | Представление (UI). Работает с контроллером, отображает данные и передаёт действия пользователя |

## 🧱 Требования

- **.NET Framework** (или .NET, в зависимости от целевой версии проекта)

## ⚙️ Настройка

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/your-username/ado-authors-crud.git
   ```

2. **Создайте базу данных**

   Пример SQL-скрипта для создания таблицы `Authors`:

   ```sql
   CREATE TABLE Authors (
       Id       INT IDENTITY(1,1) PRIMARY KEY,
       FullName NVARCHAR(100) NOT NULL
   );
   ```

3. **Укажите строку подключения**

   В классе `DbConnection` (или в `App.config`) замените строку подключения на свою:

   ```csharp
   private const string ConnectionString =
       @"Server=YOUR_SERVER;Database=YOUR_DB;Trusted_Connection=True;";
   ```

4. **Соберите и запустите проект** в Visual Studio (`F5`).

---

## 🚀 Как пользоваться

1. Запустите приложение.
2. В главном окне отобразится таблица со списком авторов.
3. Используйте кнопки **Загрузить / Добавить / Обновить / Удалить ** для выполнения соответствующих операций.
4. Все изменения сразу сохраняются в базе данных через `DbAuthorsController`.

## 🧩 Пример использования контроллера

```csharp
var controller = new DbAuthorsController();

// Получить всех авторов в DataTable
DataTable dt_authors = controller.Loading();

// Добавить автора
controller.TryInsert("Имя", "Фамилия"); 	     	// вернет true в случае успеха 

// Обновить
controller.TryUpdateAuthor(id: 1, "Имя", "Фамилия");  	// вернет true в случае успеха

// Удалить
controller.TryDeleteAuthor(id: 1);			// вернет true в случае успеха
```
